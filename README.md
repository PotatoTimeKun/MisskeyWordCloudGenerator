# Misskey WordCloud Generator

Misskeyサーバー（`sushi.ski` や `misskey.io` など）のアカウント名から最新のノートを取得し、頻出キーワードや**カスタム絵文字（`:emoji:`）の画像**を美しく埋め込んだスタイリッシュなワードクラウドを生成・ダウンロード・**MisskeyShare**で共有できる静的ウェブアプリケーションです。

---

## 🌟 主な機能

1. **Misskey API連携**
   - **サーバーホスト**: `sushi.ski`, `misskey.io`, `nijimiss.moe` など任意のMisskeyインスタンスに対応
   - **ユーザーノート取得**: `/api/users/show` でユーザーを特定し、`/api/users/notes` から直近のノート（最大200件）を取得
   - **MFM・URL・メンション除去**: 投稿本文から装飾タグやURLを適切にクレンジング

2. **カスタム絵文字（`:emoji:`）の検出＆画像埋め込み**
   - ノートに含まれる `:emoji_name:` や `:emoji_name@remote:` を単語として自動抽出
   - `/api/emojis` やノート付随の絵文字情報から画像URLを特定
   - **Canvasにカスタム絵文字画像を直接描画**: 文字の大きさに応じたサイズでワードクラウド内に美しくレイアウト
   - CORS対応による安全なPNG画像保存（フォールバック付き）

3. **ビジュアルカスタマイズ**
   - **カラーパレット**: Misskeyライム、サイバーネオン、サンセット、オーシャン、オーロラ、モノトーン
   - **背景デザイン**: ディープダーク、ネオングラデーション、ミッドナイト、ライト
   - **最大単語数**: 20〜100語
   - **配置角度**: 水平＆垂直ミックス、すべて水平、ダイナミック

4. **結果画面・出力・共有**
   - **高解像度PNG保存**: タイトルや外枠入りのカード画像として保存
   - **MisskeyShare 連携**: [MisskeyShare](https://misskeyshare.link/) ポップアップでワンクリックノート投稿
   - **頻出キーワード TOP 15**: カスタム絵文字アイコン付きのタグ一覧。クリックでCanvas上の該当単語・絵文字を強調表示

## 🚀 動作確認方法

静的ファイル（HTML/CSS/JS）のみで構成されています。

```bash
# ローカルサーバー起動例 (Python)
python -m http.server 8080
```
ブラウザで `http://localhost:8080` を開き、サーバーホスト（例: `sushi.ski`）とユーザー名（例: `sushi`）を入力して「ワードクラウドを作成する」を実行してください。
